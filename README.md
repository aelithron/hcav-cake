# hcav-cake ![IMG](https://hackatime-badge.hackclub.com/U08RJ1PEM7X/hcav-cake)
a silly little project with an interactive 10-layer cake! this was created for the [hcav scavenger hunt](https://hcav.hackclub.community) (run by the hack club community), specifically #94: "A cake, consisting of exactly 30% AI usage. [30 clanker points]".

## how to use
just [open it](https://aelithron.github.io/hcav-cake) in a browser! the site is fairly static as of now, but it has some key things:
- the flames on the candles flicker/pulse
- click on the gradients to turn them around
- click on "never" for a special surprise

## ai declaration
i spoke with neven (in dms) to make sure it would be okay to use ai for the 30% ai requirement. 
i prompted it to add three slices:
- one of its choosing
- one more grounded in something ai based
- one ai-made gradient (to compliment my human made one)

by coding time, i did ~90% of the time with zero ai. the other ~10% was exclusively ai, though i did iterate on prompts with it for a while since it kept making mistakes. gpt 5.6 luna was the specific model used, through github copilot in vs code. this readme is 100% human work as well.
